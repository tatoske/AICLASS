# AIClass - Backend Alternativo (Python FastAPI)

Servidor backend alternativo para **AIClass**, construido sobre **FastAPI**, **Pydantic** y **Uvicorn**.

## Requisitos
- **Python 3.10** o superior

## Instalación y Ejecución
```bash
# 1. Instalar dependencias:
pip install -r requirements.txt

# 2. Iniciar servidor:
python main.py

# O hacer doble clic en:
run.bat
```

## Servicios y Rutas Clave
- **Servidor Base:** `http://localhost:8000`
- **Swagger OpenAPI Docs:** `http://localhost:8000/docs`
- **ReDoc:** `http://localhost:8000/redoc`
