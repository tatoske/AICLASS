# AIClass - Frontend (React + Vite + TypeScript)

Interfaz de usuario moderna y de alto impacto para la plataforma **AIClass**.

## Tecnologías
- **React 18**
- **Vite**
- **TypeScript**
- **Axios** (Cliente API centralizado con switch interactivo Java :8080 / Python :8000)
- **Lucide Icons**

## Instalación y Ejecución

```bash
# 1. Instalar paquetes:
npm install

# 2. Iniciar servidor de desarrollo:
npm run dev
```

El aplicativo estará disponible en `http://localhost:5173`.
